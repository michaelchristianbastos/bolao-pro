# Casos de Uso - Bolão Pro

## UC-001 - Criar Bolão

**Ator Principal:**
Administrador do Bolão

**Objetivo:**
Permitir a criação de um novo bolão com todas as configurações necessárias.

### Fluxo Principal

1. O administrador acessa o painel.
2. Clica em "Criar Bolão".
3. Informa os dados do bolão.
4. Define as regras.
5. Configura a pontuação.
6. Configura a premiação.
7. Salva o bolão.
8. O sistema gera um código e um link de convite.
9. O bolão fica disponível para receber participantes.

**Resultado Esperado:**
Bolão criado e pronto para uso.
