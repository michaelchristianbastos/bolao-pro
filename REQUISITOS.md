# Bolão Pro

## Objetivo

Sistema profissional de gerenciamento de bolões de futebol.

## Funcionalidades

- Cadastro de usuários
- Cadastro de bolões
- Cadastro de campeonatos
- Cadastro de rodadas
- Cadastro de jogos
- Cadastro de palpites
- Ranking automático
- Atualização automática dos resultados
- Integração com WhatsApp
- Painel administrativo
- Área do participante
- Estatísticas
